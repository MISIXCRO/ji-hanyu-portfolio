# 冀涵宇 · 建筑与空间作品集

中文个人作品集，展示胶囊重生、音乐乌托邦、滨海地带、遗失的历史四个建筑作品。

HTML / CSS / JavaScript 静态网站；包含本地图片、旋转作品画廊、项目详情、动效、图片查看器及PDF下载。无需数据库、模型API或在线字体服务。

## GitHub Pages

仓库名：`ji-hanyu-portfolio`。在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支 **codex/portfolio-publish**、目录 **/(root)**，保存后等待部署完成。

预计站点地址：https://misixcro.github.io/ji-hanyu-portfolio/

该地址只有在仓库推送并成功启用 Pages 后才可用。免费托管不代表所有中国大陆网络都稳定可达；正式放入简历前需在关闭VPN的手机流量和Wi-Fi上测试首页、项目页及PDF下载。

## 文件

- `index.html`：首页。
- 四个项目HTML：项目详情。
- `assets/`：本地作品图片与PDF。
- `.nojekyll`：直接发布已有静态文件。
- `404.html`：保留项目路径的错误页。

保持本目录结构上传，勿只上传ZIP文件。HTML、CSS、JS和assets必须同处仓库根目录。

React Bits / PrismaticBurst
https://github.com/DavidHDev/react-bits

The PrismaticBurst GLSL shader in prismatic.js was adapted from the component source
supplied by the site owner. This website replaces the React/OGL wrapper with a
native WebGL2 renderer, adds bounded resolution, reduced-motion still rendering,
visibility lifecycle handling, a shared modal backdrop and context-loss recovery. The descending
smoothstep expression is written as 1.0 - smoothstep with ascending edges for
defined GLSL behavior. Source license:

React Bits / CircularCarousel

The gallery cylinder in circular-carousel.js and circular-carousel.css adapts the
complete component source and configured usage supplied by the site owner.
The native DOM version retains the cylinder geometry, eight-strip card curvature,
assemble entrance, spring focus, inertia, drift and pointer parallax. The React
wrapper is replaced with the existing static site controls and original artwork.
